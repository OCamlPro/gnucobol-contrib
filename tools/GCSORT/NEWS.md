# NEWS for GCSort

## Changes in 01.06.00 (2026-10-30)

* **New feature:** libgcs module to enable the use of gcsort functions from C modules.
* **New feature:** New EXTSM module for interfacing via FCD3 for sort/merge operations called from COBOL. Sort in memory; if memory limits are exceeded, the sort will use MMF (Memory-Mapped File) files.
